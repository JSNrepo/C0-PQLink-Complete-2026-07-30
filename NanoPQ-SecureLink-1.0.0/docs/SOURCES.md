# Primary sources

- FIPS 205, *Stateless Hash-Based Digital Signature Standard*:
  <https://nvlpubs.nist.gov/nistpubs/fips/nist.fips.205.pdf>
- RFC 8554, *Leighton-Micali Hash-Based Signatures*:
  <https://www.rfc-editor.org/rfc/rfc8554>
- NIST SP 800-208, *Recommendation for Stateful Hash-Based Signature Schemes*:
  <https://csrc.nist.gov/pubs/sp/800/208/final>
- NIST SP 800-232, *Ascon-Based Lightweight Cryptography Standards for
  Constrained Devices*:
  <https://csrc.nist.gov/pubs/sp/800/232/final>
- RFC 5869, *HMAC-based Extract-and-Expand Key Derivation Function*:
  <https://www.rfc-editor.org/rfc/rfc5869>
- FIPS 203, *Module-Lattice-Based Key-Encapsulation Mechanism Standard*:
  <https://nvlpubs.nist.gov/nistpubs/fips/nist.fips.203.pdf>
- NIST IR 8545, *Status Report on the Fourth Round of the NIST Post-Quantum
  Cryptography Standardization Process*:
  <https://nvlpubs.nist.gov/nistpubs/ir/2025/NIST.IR.8545.pdf>
- Cisco `hash-sigs`, RFC 8554 reference implementation:
  <https://github.com/cisco/hash-sigs>
- Becker et al., constrained ThreeBears/AVR implementation study:
  <https://orbilu.uni.lu/bitstream/10993/48811/1/CARDIS2020.pdf>
- CTRU-Light AVR artifact:
  <https://github.com/whYBeKim/CTRU-Light-and-PQC-on-AVR>

Source values from other hardware are retained only as prior-art evidence, not
as measurements of this implementation.
